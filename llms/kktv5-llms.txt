# KK直播 (KK Live)

> KK直播 (KK Live) is a Chinese mobile-first video livestreaming and social entertainment platform operated by 杭州米络文化传播有限公司 (Hangzhou Melot Culture Communication Co., Ltd.), part of 米络星集团 (Melot Group) of Hangzhou. Founded in 2012, it combines talent/performance livestreaming with interactive social features — virtual gifting, bullet comments (弹幕), multi-person live connections, PK mini-games, karaoke and outdoor streaming. The company reports 100,000+ independent streamers, 600+ partner talent agencies and 150 million registered users.

KK Live is a business-to-consumer product. As of 2026-07-19 it publishes **no public developer portal, API documentation, SDKs, or machine-readable API specifications**. This file is generated by the API Evangelist enrichment pipeline from the company's public website; it is not a provider-published llms.txt.
